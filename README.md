# ISP Competitor Benchmark Visual Moodboard (Link3 Research)

This standalone folder contains the interactive visual moodboard benchmarking **34 leading ISP websites** across South Asia, Southeast Asia, North America, and Europe.

## 🚀 How to View
* **Option 1 (Direct Double-Click):** Double-click `index.html` or `competitor_visual_moodboard.html` to open directly in any modern desktop browser (Chrome, Edge, Firefox, Safari). Zero server or installation required.
* **Option 2 (Host Anywhere):** Drop this folder into Netlify, Vercel, GitHub Pages, or any static web server.

---

## 🎨 Interactive Features Included
1. **Interactive Fullscreen Image Viewer:** Click any card to launch the Figma-grade canvas modal.
2. **Section Quick-Jump Bar:** Click `[🎯 Hero]`, `[💳 Plans & Pricing]`, `[⚡ Speeds & Tech]`, `[📦 Add-ons / Wifi]`, or `[📋 Footer & FAQ]` (Hotkeys: `1` to `5`) to glide to specific sections.
3. **Radar Navigator (Minimap):** Interactive real-time minimap in the lower right. Drag the blue lens or click anywhere on the radar to jump across the 10,000px+ full-page screenshots.
4. **2.5× Detail Magnifier Loupe:** Click `[🔍 Loupe (2.5x)]` (or press `L`) to inspect fine-print plan details, router specs, and pricing terms.
5. **Zoom Engine:** Quick triggers for `Fit Width`, `100% (1:1)`, `150%`, `200%`, plus `Ctrl + Mouse Wheel` zooming and double-click to zoom.
6. **Smooth Hand Tool Pan:** Click & drag anywhere on the canvas (or hold `Space` + drag) to pan freely.
7. **Region Filter Tabs:** Filter across South Asia (7), Southeast Asia (15), North America (4), and Europe (8).
