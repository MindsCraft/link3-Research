# ISP Competitor Benchmark Visual Moodboard (Link3 Research)

An interactive, presentation-ready visual benchmarking research suite analyzing **40 leading Internet Service Providers (ISPs)** across South Asia, Southeast Asia, North America, and Europe.

Built for executive presentations, product strategy, and design alignment for Link3's next-generation web experience.

---

## 🚀 Quick Start / How to Present

* **Direct Double-Click (Zero Setup):** Double-click `index.html` or `competitor_visual_moodboard.html` to open directly in any modern desktop browser (Google Chrome, Microsoft Edge, Safari, Firefox).
* **Completely Standalone & Offline:** Zero build steps, zero Node.js dependencies, and zero web server required. All 40 high-resolution full-page desktop captures (1440px width) are bundled in the `screenshots/` directory.
* **Web Hosting (Optional):** Can be deployed instantly by uploading this folder to Netlify, Vercel, GitHub Pages, or an internal static file server.

## 🧭 Interactive Presentation Controls

When presenting or inspecting an ISP landing page:

| Feature | Key / Interaction | Purpose |
| :--- | :--- | :--- |
| **Open Card** | Click any card in the grid | Launches the high-resolution, Figma-grade canvas inspection modal. |
| **Focus Jump** | Buttons or keys `1`–`5` | Instant glide to key landing page zones:<br>• `1`: 🎯 **Hero** (Headline, primary CTA, banner)<br>• `2`: 💳 **Plans & Pricing** (Tiers, speed badges, billing period)<br>• `3`: ⚡ **Speeds & Tech** (Latency benchmarks, fiber infrastructure)<br>• `4`: 📦 **Add-ons / Wifi** (Routers, mesh pods, OTT streaming)<br>• `5`: 📋 **Footer & FAQ** (Fine print, regulatory disclosures, contact) |
| **Radar Minimap** | Bottom-right interactive widget | Real-time viewport position preview. Click or drag the blue lens to effortlessly navigate long 10,000px+ pages. |

| **Pan Canvas** | Click & drag (or `Space` + drag) | Natural panning across the high-resolution desktop capture. |
| **Live Link** | Click `[Visit Live Site ↗]` | Direct external link to the live operator URL for real-time verification. |
| **Close Modal** | `Esc` or `Close` button | Return to the 4-region comparative grid overview. |

## 🎯 Key Strategic Takeaways for Link3

1. **Radical Pricing Transparency Wins:** Modern benchmarks (Google Fiber, Sonic, init7) have discarded hidden equipment fees, price hikes after month 12, and vague fine print. Link3 should lead the regional market with upfront, honest pricing.
2. **Speed & Latency as Table Stakes:** Leading ISPs highlight low latency, gamer peering, and Wi-Fi 6/7 hardware capabilities directly in their hero value propositions.
3. **Interactive Visual Configurators:** European and Southeast Asian leaders (Singtel, AIS, Free, Swisscom) utilize interactive speed selectors and hardware add-on pickers that demystify bandwidth needs for non-technical customers.
4. **Prepaid & Flexible Tenure Models:** Southeast Asian innovations like Globe's sachet reload prepaid fiber and Tata Play's duration discount selector offer key insights for Link3's consumer tiering.
